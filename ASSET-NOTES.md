# Asset provenance and visual decisions

- `assets-source/facade.png`: generated with the built-in image generation tool for Sumo World. Prompt: seamless orthographic dark graphite cyberpunk tower facade, realistic office windows, cyan/magenta and warm illuminated rooms, weathered panels; no sky, ground, perspective or text. Master copy, moved out of `public/` so it is no longer shipped.
- `public/assets/facade.webp`: the runtime building texture, encoded from `assets-source/facade.png` with `cwebp -q 84 -m 6` (2.9 MB to 0.33 MB, same 1536 x 1024 resolution). Mapped in world space at 33 m x 22 m per tile with a per-building offset and window tint.
- `assets-source/concept.png`: generated in the architecture task; visual reference only, never rendered. Moved out of `public/` so it is no longer shipped.
- `src/app/icon.svg`: original browser-tab icon drawn by the production team (diamond and dot in the HUD palette). No third-party artwork.
- Car, characters, roads, buildings and props: original procedural Three.js geometry authored for this prototype. This is an intentional 3D prototype departure from the image-based asset workflow; flat sprites cannot substitute for the requested explorable geometry.
- Road microtexture, signs and light pools: original procedural textures. Sign names are fictional (SUMO, NOVA, AFTERHOURS, NEON MARKET, ORBIT, NIGHT CITY, HIKARI NOODLE, TRANSIT TERMINAL) and are drawn into one canvas atlas. No licensed car logos or third-party model assets are used.
- Building silhouettes (podiums, setbacks, twin towers, rooftop plant), street furniture and the road wetness/puddle shader: original procedural geometry and GLSL written for this project (world team). No external assets.
- Lighting environment (render team): generated procedurally at start-up from emissive panels, a sky gradient and a moon disc rendered to a PMREM map (`src/game/render/environment.ts`). No HDRI or other image asset is used.
- Engine audio: generated locally by Web Audio oscillators; no sampled music or sound packs.
- Weather (rain streaks, ground splashes, lens drops, tyre-spray puff, lightning flash) and thunder audio: original procedural shaders, generated textures and Web Audio filtered noise authored in `src/game/weather/`; no image, model or sound assets are used.
- `public/models/sumo-gt.glb` (Sumo GT): original fastback GT coupe designed for Sumo World and generated reproducibly by `tools/car/build_car.py` in Blender 5.2 (headless). No real car brand, badge, logo or third-party model or texture is used; the file carries geometry and named materials only. The runtime replaces its materials with procedural ones (`src/game/vehicle/carMaterials.ts`), including a generated paint-flake normal map.
- `docs/screenshots/integrated-*.png`: captured by the integrator from the local production build in headless Google Chrome (ANGLE Metal, 1280 x 720, DPR 1), then downscaled to 960 px wide and quantised with pngquant to keep each file near 200 KB. Original game imagery; no third-party content.
- Inter and Barlow Condensed: self-hosted Fontsource packages; their licence files are retained in package dependencies.

Visual review ledger: retained graphite/cyan/magenta palette; retained night/rain atmosphere; retained third-person rear driving composition; added functional, code-native HUD with objective, map and speed; deliberately simplified architecture and vehicle detail; used inexpensive road light pools in place of photoreal reflections. The HUD is a necessary implementation extension of the original concept, which contained no UI. No screenshot UI is used.
